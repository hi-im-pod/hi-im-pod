# Garrett Ennis

AI security researcher at the [SecAI Lab](https://secai.skku.edu/), Sungkyunkwan University (SKKU), and a security engineer by background.

I work on both sides of one problem: how AI assistance changes what an attacker can do at scale, and what a defender needs to keep pace. Before research I designed SOC architectures and SIEM ingestion pipelines for regulated environments, led a security engineering and incident response team, and ran application penetration tests.

## What I am working on

- **AI-assisted malware analysis for detection rules** (thesis). Whether an agent that chooses its own analysis steps writes Sigma rules that catch more malware, with fewer false alerts, than a fixed workflow. Approved October 2026.
- **Evaluating autonomous pentest agents.** A sealed-lab study of what an autonomous LLM penetration-testing platform does unsupervised, and how much of it the detection shipped alongside it catches. Early read: almost none.
- **[APT Explorer](https://github.com/hi-im-pod/apt-explorer).** An open-data explorer that merges APT actor records across MITRE ATT&CK, MISP, ETDA and Malpedia, so one vendor's alias does not hide the reports filed under another.

## Background

SOC architecture and SIEM ingestion pipelines for more than 30 CMMC government-contractor clients, enterprise application penetration testing at Walmart Global Tech, and detection engineering across endpoint, firewall and cloud telemetry.
